# 🐕 K9 Search Team - Fun Competition App

ระบบคิดคะแนนการแข่งขันสุนัขค้นหาและกู้ภัยที่ใช้งานง่าย สนุก และปรับแต่งได้!

## ✨ ฟีเจอร์ใหม่ทั้งหมด!

### 🎨 **ดีไซน์ใหม่หมด**
- UI สวยงาม ทันสมัย ดูเป็นมิตร
- สีสันสดใส ดูสนุกสนาน
- แอนิเมชันน่ารักๆ
- Responsive รองรับทุกขนาดหน้าจอ

### 📝 **ลงทะเบียน (Register)**
- ฟอร์มลงทะเบียนที่ใช้งานง่าย
- แสดงรายการทีมแบบการ์ดสวยๆ
- ลบทีมได้ทันที
- จำกัด 20 ทีม (แต่สามารถปรับได้ในโค้ด)

### ⏱️ **คิดคะแนน (Judge)**
- **จับเวลาง่ายๆ** ปุ่มเดียว เริ่ม/หยุด/รีเซ็ต
- **Toggle Switch** ปัดเพื่อบันทึกว่าพบ VP หรือไม่
- **เกรดด้วยดาว** ⭐⭐⭐⭐⭐ ง่ายต่อการเลือก
- **คะแนนสด** คำนวณและแสดงผลทันที
- **Quick Checklist** ติ๊กเดียวเสร็จ
- **สีเขียวขึ้นเมื่อพบ VP** ให้ Feedback ทันที

### 🏆 **ตารางคะแนน (Leaderboard)**
- **จัดอันดับอัตโนมัติ** เรียงตามคะแนน
- **เหรียญรางวัล** 🥇🥈🥉 สำหรับ 3 อันดับแรก
- **แก้ไขคะแนนได้** ✏️ กดแก้ไขทีมใดก็ได้
- **ลบคะแนนได้** 🗑️ หากบันทึกผิด
- **ส่งออก CSV** 📥 สำหรับการรายงานผล

### ⚙️ **ตั้งค่า (Settings)** 🆕
- **ปรับคะแนน VP** เปลี่ยนคะแนน VP1, VP2, VP3 ได้
- **ปรับเกรด** เปลี่ยน % ของแต่ละเกรดได้
- **ปรับคะแนนแต่งกาย** เปลี่ยนคะแนนรายการบังคับ/พิเศษได้
- **ปรับคะแนนโบนัส** เปลี่ยนคะแนนโบนัสแต่ละรายการได้
- **บันทึกตั้งค่า** ค่าที่ตั้งไว้จะถูกจำไว้

## 🎯 การใช้งาน

### 1. เปิดแอป
เปิดไฟล์ `index.html` ในเบราว์เซอร์
หรือรัน Server: `python3 -m http.server 8000`

### 2. ลงทะเบียนทีม
1. คลิกปุ่ม "➕ ลงทะเบียน"
2. กรอกข้อมูลสุนัขและผู้ควบคุม
3. กด "✨ ลงทะเบียน"
4. ทำซ้ำจนครบทุกทีม

### 3. คิดคะแนน
1. คลิกปุ่ม "📝 คิดคะแนน"
2. เลือกทีมจากรายการ
3. **เริ่มจับเวลา** เมื่อสุนัขเริ่มค้นหา
4. **บันทึก VP**: Toggle เมื่อพบ + เลือกเกรดดาว
5. **ติ๊กการแต่งกายและโบนัส**
6. ดู**คะแนนสด** ปรับเปลี่ยนทันที
7. กด "💾 บันทึกคะแนน"

### 4. ดูและแก้ไขตารางคะแนน
1. คลิก "🏆 ตารางคะแนน"
2. ดูอันดับการแข่งขัน
3. แก้ไขคะแนน: กด "✏️ แก้ไข"
4. ลบคะแนน: กด "🗑️ ลบ"
5. ส่งออก CSV: กด "📥 ส่งออก CSV"

### 5. ปรับแต่งกติกา (Settings)
1. คลิก "⚙️ ตั้งค่า"
2. ปรับค่าต่างๆ ตามต้องการ
3. กด "💾 บันทึกตั้งค่า"
4. หรือกด "🔄 คืนค่าเดิม" หากต้องการค่าเริ่มต้น

## 📊 ระบบคะแนน (ค่าเริ่มต้น)

### คะแนนผู้ประสบภัย (VP)
- **VP1 (ง่าย)**: 20 คะแนน
- **VP2 (กลาง)**: 30 คะแนน
- **VP3 (ยาก)**: 40 คะแนน

### เกรดการแจ้งเตือน (% ของคะแนน VP)
- **V (96-100%)**: แจ้งชัดเจน ต่อเนื่อง
- **SG (90-95%)**: แจ้งชัด แต่ไม่ต่อเนื่อง
- **G (80-89%)**: แจ้งไม่ชัด
- **B (70-79%)**: หาเจอ แต่แจ้งไม่ชัด
- **M (<70%)**: หาไม่เจอ / ไม่แจ้ง

### คะแนนการแต่งกาย (10 คะแนน)
- **บังคับ**: รองเท้า, เสื้อแขนยาว, กางเกงขายาว (2 คะแนน/ชิ้น)
- **พิเศษ**: หมวก, ถุงมือ (2 คะแนน/ชิ้น)

### คะแนนโบนัส (35 คะแนน)
- หา VP1 ใน 1 นาที → +10
- หา VP2 ใน 2 นาที → +10
- หาครบ 3 VP ใน 3 นาที → +10
- สั่งหมอบรอได้ → +5

**รวมสูงสุด: 135 คะแนน** 🎯
